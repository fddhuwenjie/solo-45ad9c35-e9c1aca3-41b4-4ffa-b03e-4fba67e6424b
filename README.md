# 藏品转运回温编排（冬季借展结露防护）

冬季借展时，冷藏车中的藏品箱直接进入暖湿展厅若立即开箱，冷表面会低于环境
露点而结露；但一直密封又会挤占布展时间。本系统用于逐箱编排"进场 → 静置 →
拆外包装 → 开箱"的时机：给出箱内温度、露点差、温湿度变化率的逐段估算，叠加
记录仪实测曲线，指出最早发生风险的位置和**尚需等待多久**，并把每次安排与已发生
事件封存为不可变版本；实测偏离原计划时**从偏离点另建修订，不改历史**。

## 技术栈

- 后端：Python + Flask（`app/`），计算引擎 `thermal.py` 仅用标准库
- 存储：SQLite（当前工作单 + 版本快照，`data/acclimation.sqlite3`）
- 前端：原生 JavaScript + 手写 SVG 图表（无框架、无 CDN 依赖）

## 运行

```bash
# 已在 ./.pylibs 内置 Flask（离线环境）；有 pip 时亦可 pip install -r requirements.txt
./run.sh                 # http://localhost:5000
# 或指定端口
PORT=8080 ./run.sh
```

打开页面后点 **"载入示例行程"**：一趟 2026-01-15 从 -22°C 严寒室外经
-18°C 冷藏车、12°C 卸货平台进入 21°C/55%RH 展厅的行程，含三件包装与材质
各不相同的藏品；再到"记录仪"标签载入同捆的示例 CSV（也可点页面顶部
"导入记录仪 CSV"，接口同样提供 `/api/sample/logger.csv`）。

## 计算模型（摘要，完整参数见导出 JSON）

- **箱温**：集总热容一阶热响应，`τ = C·ΣR × tau_multiplier`（h），
  `dT/dt = (T_amb−T)/τ`，逐分钟欧拉积分；拆除外包装/开箱时对应层的热阻移除，
  全部拆除后 τ 下限 0.25 h。
- **水汽**：密封期箱内绝对湿度不变（冷箱进暖房后 RH 反而下降，**结露来自
  外包装外表面/开箱瞬间的暖湿空气**）；开箱后 `dx/dt = k_open(x_amb−x)`，
  仍有内衬残留时交换率折减 1/4。
- **露点**：Magnus 公式（17.27/237.3）；露点差 = 冷表面温度 − 露点，
  密封期对环境露点、开箱后对箱内露点。
- **变化率**：60 分钟滚动平均的 °C/h、%RH/h。
- **安全时刻**：从计划节点向后，露点差、升温率、湿度变化率全部连续 30 分钟
  达标的最早时刻；"尚需等待"= 安全时刻 − 计划时刻。
- **实测偏离**：实测箱温与估算持续 6 个采样点相差 ≥ 2°C（可调）即报偏离点；
  建修订时以黄金分割搜索重新拟合 τ 系数，偏离点之前的节点锁定为历史。
- **风险种类**：结露（危险）、露点差不足、升温过快、湿度变化过快、
  记录仪断档（默认 >30 min）、静置不足；均只在"进场"之后评估。

## 界面与操作

- 路线时间带四条图：温度（灰实线=环境、灰虚线=环境露点、彩线=箱内估算、
  彩虚点=记录仪实测）、冷表面露点差（0 线以下为结露区，彩虚线为该箱材料
  限值）、升温率、RH 变化率；底部节点带可拖移 **进场/静置/拆外包装/开箱**
  四类节点（5 分钟对齐）。
- 顶部横幅：最早风险的时间、箱号、类型与最保守的等待时长。
- 时刻表：每箱节点、静置时长是否够、计划/建议安全时刻、"封存"按钮。
- **封存**：已发生事件写入 SQLite 版本（kind=sealed），节点显示挂锁，
  不可再拖移；重复封存同箱同事件以最新一次为准。
- **从偏离点建修订**：检测到持续偏离后可用（kind=revision），锁定偏离点
  之前的节点并拟合热响应系数，历史版本仍可随时查看。
- 右侧编辑器：阶段温湿度/时段、每箱包装层（热阻热容、拆除时机）、材料限值、
  记录仪 CSV、以及直接编辑整份 JSON。
- 成果导出：
  - 现场操作单（可打印/PDF）：`/sheet/<行程编号>`，版本可加 `?v=<id>`；
  - 计算参数 JSON：顶部"参数 JSON"按钮，或 `GET /api/trip/<code>/params.json`。

## 主要接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/sample/load` | 载入/重置示例行程 |
| GET | `/api/sample/logger.csv` | 示例记录仪数据（含 C-02 偏离、C-03 断档） |
| POST | `/api/calculate` | 入参整份 document，返回逐分钟网格与风险 |
| POST | `/api/parse-csv` | 解析记录仪 CSV（multipart 文件或 `{text}`） |
| PUT | `/api/trip/<code>/document` | 保存当前工作单 |
| POST | `/api/trip/<code>/events` | 封存已发生事件 |
| POST | `/api/trip/<code>/revision` | 从实测偏离点建修订 |
| POST | `/api/trip/<code>/versions` | 封存当前计划版本 |
| GET | `/api/trip/<code>/versions`、`/api/version/<id>` | 版本列表/详情 |
| POST | `/api/params` | 计算参数 JSON 下载 |

CSV 格式：`case_id,timestamp,temp,rh`（`YYYY-MM-DDTHH:MM`）。

## 说明

模型为编排用途的工程近似（集总参数、分层热阻），安全余量通过材料限值与
"连续 30 分钟达标"体现；现场若出现表面水雾等征兆应立即停止操作并恢复密封。
